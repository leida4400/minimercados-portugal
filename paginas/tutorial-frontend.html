Tutorial de HTML, CSS, JavaScript y componentes Front-End

Introducción

El Front-End corresponde a la parte visual de una aplicación web con la que interactúa directamente el usuario.

En el proyecto Minimercados Portugal se utilizan diferentes tecnologías para construir una interfaz organizada, clara y fácil de utilizar.

1. HTML

¿Qué es HTML?

HTML es el lenguaje utilizado para construir la estructura de una página web. Permite organizar elementos como títulos, párrafos, enlaces, imágenes, formularios, tablas y botones.

Aplicación en Minimercados Portugal

En Minimercados Portugal, HTML permite construir la estructura de las diferentes páginas del sistema, como Dashboard, Productos, Inventario, Clientes, Proveedores, Ventas, Compras, Caja y Reportes.

Ejemplo: Un elemento HTML puede utilizarse para crear un título, un botón o una tabla dentro de una página.

2. CSS

¿Qué es CSS?

CSS permite definir la apariencia visual de una página web. Se utiliza para establecer colores, tamaños, espacios, fuentes y distribución de los diferentes elementos.

Aplicación en Minimercados Portugal

En nuestro proyecto CSS permite personalizar la apariencia de las interfaces y mantener una presentación visual organizada y coherente.

Ejemplo: CSS permite modificar el color de fondo, tamaño de los textos, espacios y presentación de los botones.

3. JavaScript

¿Qué es JavaScript?

JavaScript es un lenguaje de programación que permite incorporar comportamiento e interacción a las páginas web.

Aplicación en Minimercados Portugal

JavaScript puede utilizarse para validar formularios, controlar acciones de los usuarios e interactuar con los diferentes elementos de la interfaz.

Ejemplo: JavaScript puede mostrar un mensaje cuando el usuario realiza una determinada acción.
↑ Volver al inicio

4. Bootstrap

¿Qué es Bootstrap?

Bootstrap es un framework utilizado para facilitar el diseño de interfaces web mediante componentes y estructuras previamente definidas.

Aplicación en Minimercados Portugal

En nuestro proyecto Bootstrap se utiliza como apoyo para construir componentes visuales y facilitar la adaptación de las interfaces a diferentes tamaños de pantalla.

Versión utilizada: Bootstrap 5.3.7

5. Componentes Front-End

¿Qué son?

Los componentes Front-End son elementos visuales y funcionales que forman parte de la interfaz de una aplicación web.

Componentes utilizados en Minimercados Portugal

  • Menú de navegación.
  • Botones.
  • Tarjetas.
  • Tablas.
  • Formularios.
  • Iconos.
  • Barra lateral.
  • Panel principal.
Aplicación: Estos componentes permiten organizar la información y facilitar la interacción del usuario con el sistema.
